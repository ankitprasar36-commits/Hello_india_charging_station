# Helio Charge website

A responsive, static website concept for a solar-powered EV charging service.

## Included
- Responsive navigation and mobile layout
- Station search and connector-type filters
- Sample station cards
- Booking form demo with estimated pricing
- Sample energy dashboard
- Pricing, impact, contact, and FAQ-ready sections
- No build step or framework required

## Publish on Netlify
1. Extract `helio-charge-website.zip`.
2. Open https://app.netlify.com/drop in your browser and sign in if asked.
3. Drag the extracted `helio-charge-website` folder (the folder containing `index.html`) into the drop area.
4. Netlify will publish it and provide a new public website URL.

## Important notes
- This is a separate new site; it does not overwrite the existing `solar-charging-station.netlify.app` deployment.
- Station data, availability, dashboard metrics, and rates are illustrative placeholders.
- Booking and contact forms are front-end demonstrations only. They do not create real bookings, accept payment, or send messages.
- Images and web fonts load from external providers. Replace them with your own assets if desired.
- To make this production-ready, connect a backend/database, verified charger API, real pricing, authentication if needed, and a form/booking service.
